# Aprendendo a Amidá

Livro de estudo da Amidá no nusach Edot HaMizrach (sefaradi), em português: texto hebraico, transliteração, tradução e explicações, com capítulos sobre a origem da reza, como rezar, minian, as rezas do dia, variações do ano, erros e Shabat.

Abra `index.html` no navegador para ler.

**Este livro contém o Nome de D'us em hebraico.** Páginas impressas não devem ir para o lixo comum; guarde-as com respeito ou entregue-as à guenizá.

Texto hebraico: Sidur Edot HaMizrach, edição Shaliehsaboo, no Sefaria (domínio público, CC0). Traduções e explicações preparadas para este livro. Para halachá prática, consulte o rabino da sua comunidade.
